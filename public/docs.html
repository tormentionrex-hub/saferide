Safe-Ride API

API REST para la plataforma de carpooling sostenible

Bienvenido a Safe-Ride API

Safe-Ride es una solución completa de carpooling diseñada para reducir costos de movilidad, minimizar el impacto ambiental y mejorar la eficiencia del transporte urbano en Costa Rica.

Nuestra API RESTful está construida con Node.js y Express, siguiendo las mejores prácticas de desarrollo para garantizar seguridad, escalabilidad y rendimiento óptimo.

Con autenticación basada en JWT, manejo robusto de errores y una arquitectura modular, esta API es ideal para integrarse con aplicaciones móviles y web.

El concepto surge como resultado de Belén Leaders Lab, una iniciativa impulsada por Intel Costa Rica, la alizanza Empresarial para el Desarrollo (AED), la municipalidad de Belén y el Comité Cantonal de la Persona Joven de Belén. En este un equipo de jovenes obtuvieron una recompensa para empezar a desarrollar esta solución innovadora.

Posteriormente, con la ayuda de la Universidad Latinoamerica de Ciencia y Tecnología (ULACIT) como parte de sus proyectos de TCU, se logró iniciar la contrucción de la plataforma Safe-Ride, enfocada en promover prácticas de movilidad sostenible.

Esta API proporciona todos los endpoints necesarios para gestionar usuarios, vehículos, viajes, reservaciones, reseñas y métricas de sostenibilidad.

Características Principales

🔐 Autenticación JWT

Sistema completo de autenticación con tokens de acceso y refresh tokens para máxima seguridad.

👥 Gestión de Usuarios

Roles diferenciados para conductores, pasajeros y administradores con permisos granulares.

🚕 Sistema de Viajes

Creación, búsqueda y gestión de viajes con geolocalización y filtros avanzados.

📝 Reservaciones

Sistema completo de bookings con confirmación automática y gestión de asientos.

⭐ Reseñas

Sistema de calificaciones bidireccional entre conductores y pasajeros.

📊 Métricas de Sostenibilidad

Cálculo automático de CO2 ahorrado, kilómetros compartidos y rankings de usuarios.
